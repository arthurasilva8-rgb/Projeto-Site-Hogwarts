# 🧙‍♂️ Cerimônia de Seleção

Projeto desenvolvido para praticar **HTML5 e CSS3**, criando uma página inspirada na **Cerimônia de Seleção de Hogwarts**, do universo de Harry Potter.

## 📌 Sobre o projeto

A página apresenta a Cerimônia de Seleção das casas de Hogwarts, utilizando imagens, fontes personalizadas e diferentes técnicas de estilização e organização de elementos.

O projeto foi desenvolvido sem JavaScript, utilizando apenas **HTML e CSS**.

## 📂 Estrutura do projeto

```text
cerimonia-selecao/
├── index.html
├── style.css
└── assets/
    ├── sorting_hat.jpg
    ├── gryffindor.jpg
    ├── slytherin.jpg
    ├── ravenclaw.jpg
    └── hufflepuff.jpg
```

> ⚠️ Os nomes das imagens devem ser mantidos e os arquivos precisam permanecer dentro da pasta `assets`.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Google Fonts
* Flexbox
* CSS Grid
* Glassmorphism
* CSS Transitions
* CSS Hover Effects

## 📚 Conteúdos praticados

* Estrutura básica de um documento HTML5
* Tags semânticas: `header`, `main`, `section`, `aside` e `footer`
* Uso de `class` e `id`
* Caminhos relativos para imagens
* Reset CSS
* `radial-gradient`
* Layout com Flexbox
* Layout responsivo com CSS Grid
* `repeat(auto-fit, minmax())`
* Efeito Glassmorphism com `backdrop-filter`
* Efeitos com `:hover`, `transition` e `transform`
